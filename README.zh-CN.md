# 仓鼠囤囤

> [English](README.md) | **简体中文**

集日常收支、物品收纳与资产管理于一体的轻量化个人账本。面向个人与小商户的极简双模（手账拟物 / 液态玻璃）渐进式 Web 应用（PWA）。

---

## 核心特性

- **纸感极简设计系统**：微暖纸张底色配合纯代码轻量纸浆微噪点（`<feTurbulence>`）、真实撕纸微锯齿毛边（`.paper-deckle`）、和纸胶带与实体双线印泥印章。
- **按天成张小票**：每日流水以独立纸质小票容器聚合呈现，虚线分隔，彻底拆除贯穿全屏的表格线与轧账余额噪音，阅读动线自然流畅。
- **一体化手帐便签抽屉**：平滑滑出的手帐抽屉，内置 4×4 复古桌面计算器键盘、3 列机械滚轮拨盘时间选择器与邮票方连分类网格。
- **AA 分摊与真实收支抵扣**：支持垫付报销与 AA 聚餐收款关联抵扣原支出流水，剔除虚增收入，还原真实消费水平，支持跨周期对账。
- **纯本地离线可用**：数据完全持久化于浏览器本地 IndexedDB，界面层与持久化存储完全解耦，支持完整的 JSON 与 CSV 备份导出导入。
- **10 套纸张主题**：内置竹青素笺、特种米白、复古牛皮、复写碳纸、古法靛蓝等 10 套深浅特种纸质感主题，全局通过语义 CSS 变量自适应映射。
- **微内核插件系统**：基于标准插件契约（`src/plugin-sdk/`）支持 UI 插槽自由注入、组件覆写、洋葱模型业务中间件拦截与通用隔离存储。默认搭载“持有物品（Owned Items）”标准插件，支持大件数码物品全生命周期追踪与日均持有成本核算。

---

## 技术栈

- **前端框架**：React 19 + TypeScript
- **构建工具**：Vite + `@vite-pwa/plugin`
- **样式方案**：Tailwind CSS v4 + 全局主题语义变量
- **图标体系**：Lucide React（纯矢量线条图标，界面零 Emoji）
- **状态管理**：Zustand
- **本地存储**：`idb`（轻量 IndexedDB Promise 包装）
- **测试框架**：Vitest + React Testing Library

## 快速开始

### 1. 安装依赖

本项目统一使用 `pnpm`：

```bash
pnpm install
```

### 2. 启动开发服务器

```bash
pnpm dev
```

启动后在浏览器中访问控制台输出的本地服务地址（默认 `http://localhost:5173`）。

### 3. 全量门禁校验

运行包含 ESLint、Vitest 自动化测试与 TypeScript 生产编译的三合一门禁：

```bash
pnpm check
```

## 工程规范与架构准则

1. **双语边界规范**：
   - **工程与构建层（100% 英文）**：开发者规范（`AGENTS.md`、`LESSONS.md`）、Git 提交信息、测试用例描述、CI 流程及技术注释统一使用地道简洁的英文。
   - **产品与用户界面层（中文为主）**：界面文案、分类、账户及提示信息采用凝练自然的纯中文；顶栏刊头保持西文文学衬线体（`Instrument Serif`）。
2. **代码自解释与禁止冗余注释**：严禁叙事性分块横幅注释（如 `// ====`、`{/* 容器 */}`），代码必须通过清晰的命名与测试自表达意图。
3. **严格门禁与零警告标准**：CI 自动运行 `pnpm check`，要求 ESLint 零错误零警告、TypeScript 零 `any`、测试用例 100% 通过。
