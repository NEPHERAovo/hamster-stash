# 有机文具记账簿设计系统规范

本指南为 **仓鼠囤囤（HamsterStash）** 专有设计准则。所有涉及用户界面、交互动效、排版与视觉样式的代码必须严格遵循本规范。

---

## 1. 核心设计原则

将数字记账升华为手持一本有温度的旅行手帐与撕下真实棉纸票据的有机质感，兼具沉浸温度与工具效率：

### 1.1 有机纸感物理法则
1. **纸浆纤维与微噪点**：
   - 告别纯平塑料白板，全局挂载轻量 SVG 纸浆纤维滤镜（`<feTurbulence>`）。
   - 让背景与卡片如日本竹尾棉纸般，具备细密漫反射颗粒与有机呼吸感。
2. **手帐便签抽屉与按天成张小票**：
   - **按天成张小票**：流水列表彻底告别分散与表格垂直线，同一天的“日期头部”与“当天流水”聚合在独立的纸质小票容器内（`bg-(--paper-sheet)`，`rounded-[2px]`，`shadow-[0_2px_8px_rgba(0,0,0,0.04)]`，垂直间距 `mb-3.5`）。日期头部与明细之间采用 `1px dashed` 虚线分隔，笔与笔之间采用浅虚线分隔，末项去除底边，强化“一张张小票陈列在网格书桌上”的手帐秩序；
   - **纯净流水阅读动线**：时间整合进副标题（`10:57 · 餐饮 · 微信零钱`），彻底移除每笔流水下方的轧账余额噪音，右侧仅保留清晰金额数字，构建“分类微标 → 事由与元数据 → 消费金额”的高效线性动线；
   - **强化顶部卡片视觉重心**：月度结余卡改用纯白棉纸底色与高反差浮起投影（`shadow-[0_8px_24px_-4px]`），与底层的点阵网格纸形成鲜明层次，底部锯齿毛边联动纯白；
   - **手帐便签小票抽屉**：
     - **顶部锯齿**：抽屉顶沿通过 CSS/SVG 实现经典小票锯齿（`.paper-sawtooth-top`），外层容器保持 `overflow: visible` 彻底杜绝锯齿被父容器裁剪；顶部居中固定和纸胶带（`.washi-tape`）；
     - **金额区小票虚线**：金额数字上下贯通 `1px dashed` 虚线，呈现票据存根感；
     - **4 列分类邮票方连**：分类统一采用 4 列网格（无纵向滚动条），内部采用 `1px dotted border-(--rule-hairline)` 十字点线虚线分割，彻底去除四周边框，形成如同未撕开邮票方连的纸质齿孔感；
     - **可点击标签浅底微胶囊**：`账户`、`时间`、`报销`、`凭证` 及时间面板中的 `今天 / 昨天 / 前天` 标签，统一采用主题自适应底色（`bg-(--paper-sunken) rounded-[3px]`，严禁硬编码色值），强化物理可点击暗示；
     - **报销与凭证级联联动（单行不折行）**：支出态下元数据横条默认仅展示 `[报销]` 微胶囊，隐藏 `[📎 凭证]`；仅当点击激活 `[待报销 ✓]` 时才在其右侧动态展开 `[📎 凭证]` 微胶囊（取消待报销时同步隐藏并清理附件）；确保横条默认仅由 `[账户 ▾] · [时间 ▾] · [报销] · [物品 ▾]` 4 个轻量微胶囊构成，单行整齐对齐不换行；
     - **3 列机械滚轮拨盘**：彻底移除原生系统日期与时间输入控件，采用无外框 3 列机械滚轮（日期占 2 份，小时占 1 份，分钟占 1 份），行高 `h-8`（32px），容器高 `h-24`（96px），首尾补空项占位，配合 `mask-image` 渐隐遮罩与居中两条 `1px dashed` 虚线读数窗口（中间固定等宽冒号 `:`），支持顶部快捷标签联动；
     - **备注单条虚线横线**：输入框采用 `border-b 1px dashed`。
   - **内置复古计算器键盘**：4×4 经典网格，运算符输入时自动切换为 `[ = ]`，计算完成后变为 `[ 保存 / 完成 ]`，第四行继续记账按键文案统一为 **`再记一笔`**。
3. **撕纸毛边与毛刺**：
   - 票据存根底部弃用机械虚线，采用真实物理微锯齿毛边裁切（`.paper-deckle`），如同从小票簿刚撕下的存根。
4. **和纸胶带固定**：
   - 核心存根卡片顶端中间贴有一段半透明微纤维质感的和纸胶带（`.washi-tape`），带微撕边纹理，犹如手工贴在记账本上。
5. **黄铜文具附件与功能强绑定**：
   - 严禁为了装饰而无意义堆砌。仅当账单记录挂载了发票凭证、报销单或借据附件时，右上角别上一枚精致哑光的**黄铜回形针**（`.brass-clip`）。
6. **微角度倾斜与纸角翘起阴影**：
   - 核心票据卡片带 `-0.4°` 微偏转与单角微悬空阴影（`.corner-lift-shadow`），营造随手置于桌面的真实物理落差。但操作类按钮（如右下角记账浮钮）必须保持水平正直（`transform: none`），严禁歪斜影响操作。
7. **分类方格微标**：
   - 流水行左侧统一采用 `26×26px` 锐利微方块（`rounded-xs` 2px），底色取对应分类的极淡低饱和色板，内嵌 Lucide 极细线条图标，兼顾品类辨识与克制文具秩序。
8. **印泥渗透印章**：
   - 状态印章（待报销、已报销、借款结清、AA抵扣、实付冲减）采用双线倾斜框与微飞白油墨渗透质感（`.real-stamp` / `.paper-stamp`）。
   - **AA抵扣与分摊微印章**：
     - 原支出部分分摊：朱红微印章 `实付 ¥XX.XX`（或 `已分摊 ¥XX.XX`）；
     - 原支出全额抵扣：松柏绿微印章 `已全额抵扣`；
     - 抵扣入账流水：墨绿微印章 `AA抵扣 · {原支出事由}`，明确标明属于代付款收回，不虚增收入。
9. **排版双轴**：
   - **财务与对账数据**：强制严守 `Geist Mono` 等宽数字（`tabular-nums`），保障账簿的严谨雕塑感。
   - **月份与存根大标题**：引入文学西文衬线体 `Instrument Serif`，形成书卷文学气与严谨财务度量的视觉张力。
10. **10 套文具纸张主题色板**：
    - 系统支持浅色 5 套与深色 5 套：
      - **浅色 1（默认）：🌿 竹青素笺 (`theme-sage`)**：淡雅竹影微草绿桌面底纸（`--paper-base: #EEF4ED`）搭配纯白纸质小票与便签存根（`--paper-sheet: #FFFFFF`），高反差松柏绿会计线与印章。
      - **浅色 2：📄 特种米白 (`theme-cotton`)**：经典温润暖白桌面（`--paper-base: #F5F2EA`）搭配纯白小票（`--paper-sheet: #FFFFFF`）。
      - **浅色 3：📜 复古牛皮 (`theme-kraft`)**：老羊皮纸轻焙暖黄桌面（`--paper-base: #EFE5D4`）搭配纯白便签（`--paper-sheet: #FFFFFF`）。
      - **浅色 4：🌊 雾霭蓝卡 (`theme-mist`)**：沉静清爽水彩纸蓝桌面（`--paper-base: #E7EFF5`）搭配纯白小票（`--paper-sheet: #FFFFFF`）。
      - **浅色 5：🌸 樱落绯灰 (`theme-cherry`)**：极柔和落樱微粉纸桌面（`--paper-base: #F6ECEE`）搭配纯白小票（`--paper-sheet: #FFFFFF`）。
      - **深色 1（默认）：🌑 复写碳纸 (`theme-carbon`)**：温润暖炭复写纸底色（`--paper-base: #141311`）搭配微升起的暖碳纸小票（`--paper-sheet: #22211D`），层级清晰且温和护眼。
      - **深色 2：🌌 古法靛蓝 (`theme-indigo`)**：深邃草木染蓝印花桌面（`--paper-base: #0E131C`）搭配午夜蓝小票（`--paper-sheet: #1A2434`）。
      - **深色 3：☕ 深焙浓缩 (`theme-espresso`)**：醇厚咖啡烘焙深棕桌面（`--paper-base: #14100D`）搭配暖褐浓缩纸卡（`--paper-sheet: #251E19`）。
      - **深色 4：🏛️ 黑曜石金 (`theme-obsidian`)**：哑光纯黑桌面（`--paper-base: #0B0B0B`）搭配炭黑石板小票（`--paper-sheet: #1C1C1C`）与哑光古铜印线。
      - **深色 5：🌲 幽林松柏 (`theme-pine`)**：深邃森林幽绿古纸桌面（`--paper-base: #0C140E`）搭配幽深松柏纸卡（`--paper-sheet: #19271E`）。
11. **全站手帐页眉规范与统一英文衬线刊头**：
    - 针对移动端中文在西文衬线字体下易回退至普通黑体的问题，全站主导航页面顶部大标题强制统一使用西文文学衬线刊头（`Instrument Serif`，`text-2xl sm:text-[28px]`，非斜体，`text-(--ink-solid)`）：
      - 账本页：动态西文月份大标题（如 `November 2026`）；
      - 统计页：`Statistics`（右侧保留 `周 / 月 / 年` 切换）；
      - 物品页：`Owned Items`（右侧保留 `+ 新建` 按钮）；
      - 资产页：`Assets`（右侧保留齿轮设置微按钮与 `+ 新建` 按钮）；
      - 设置子页：`Settings`（左侧保留返回按钮）；
    - 统计页周期标题同样采用英文衬线体展示（如 `November 2026` / `Year 2026`），彻底杜绝中英混排字体割裂；
    - 统一页眉固定高度（`h-14` / `px-4.5 pt-2.5 pb-2`）、背景轻度高斯模糊与底部分割发丝线；
    - 补全页眉右侧操作区（账本左右翻月、统计周期切换下划线、资产设置微按钮与新建微型按钮）。
12. **多主题与暗色模式卡片语义变量规范**：
    - **严禁任何硬编码色值**：所有小票卡片、统计卡片、资产卡片以及锯齿毛边（`.paper-deckle-bottom` / `.paper-sawtooth-top`）彻底移除硬编码色彩；
    - **自适应 10 套纸张主题**：卡片统一使用 CSS 变量 `bg-(--paper-sheet)` 或 `var(--paper-sheet)`，浅底微胶囊与空状态内嵌框统一使用 `bg-(--paper-sunken)`，在 10 套深浅特种纸下自动映射专属色板；
    - **资产页净资产存根**：将净资产总额与往来借贷待收聚合进同一张小票存根（顶部和纸胶带、底部物理微锯齿毛边 `paper-deckle-bottom`，中间以 `1px dashed` 虚线分隔）；
    - **账户列表单张小票化**：拆除各账户的独立方框，聚合进单张小票容器内；账户间以 `1px dashed` 虚线区隔，移除右侧冗余的箭头符号；
    - **主题与设置去框化**：主题 10 个选项移除矩形边框与粗黑边框，改为圆形纸样色卡配合极简品名，选中项以印章勾选角标与浅底块高亮；设置项统一收进纸质卡片，列表行之间采用 `1px dashed` 虚线区隔。
13. **持有物品与持有成本手帐系统**：
    - **独立物品一级导航**：通过 `registerNavTab` 注册，启用后底部导航栏自适应为“账本 · 统计 · 物品 · 资产”四栏均分布局；停用后自动干净卸载恢复三栏；
    - **一切以账单为核心的生成逻辑**：
      - 支出态物品托盘第一项提供一键 `[+ 将本笔支出记为新物品]` 开关胶囊，保存账单时中间件自动创建新在用持有物品并绑定购买角色；
      - 支出态第二项提供关联在用或闲置物品绑定为配件保养角色；
      - 收入态物品托盘提供选择在用或闲置物品绑定为售出回血角色，保存账单时中间件自动将物品流转为已售出并锁定结束日期；
    - **物品存根小票**：顶贴和纸胶带（`.washi-tape`）、底裁物理撕纸锯齿（`.paper-deckle-bottom`）、中轴突出展示等宽大字日均持有成本，以 `1px dashed` 虚线区分累计投入、售出回血、净持有成本与保值率；
    - **实体拟物印章**：物品状态（在用 `USING`、闲置 `IDLE`、已售出 `SOLD`、已报废 `SCRAP`）统一采用双线微倾斜印泥戳印，自适应 10 套深浅纸张主题；
    - **资产页去噪与独立设置子页**：资产页主屏彻底移除设置卡片与概述堆叠卡片，仅保留顶部净资产存根与账户列表小票；主题与设置整体剥离为独立子页 `SettingsSubPage`（刊头衬线 `Settings`），由资产页顶栏右侧齿轮微按钮滑入打开。
14. **标准插件的手帐风物理延展**：
    - 插件开发的 UI 组件必须无缝继承宿主设计语言，严禁使用现代沉重弹窗或硬编码色值；
    - 所有卡片使用 `bg-(--paper-sheet)`，微胶囊使用 `bg-(--paper-sunken)`，虚线使用 `1px dashed border-(--rule-hairline)`；
    - 插件子页与弹窗必须挂载和纸胶带（`.washi-tape`）、锯齿边缘（`.paper-sawtooth-top` / `.paper-deckle-bottom`）与实体印泥印章（`.real-stamp`），保持与主应用一致的手帐呼吸感；
    - 插件内严禁直接引用主应用非 SDK 相对路径，所有手帐原子组件必须经由 `plugin-sdk` 复用。

## 2. 反模板化红线清单

> [!CAUTION]
> 违反以下任何一条，即视为引入典型模板味，必须立即重构：

1. ❌ **严禁圆底彩圈图标与表格垂直线堆砌**：
   - 流水列表项绝不能套用大圆圈彩色图标；
   - 改为：左侧微方块分类微标（26×26px） + 单行副标题合并时间戳（`10:57 · 餐饮 · 微信零钱`） + 纯粹等宽消费金额。彻底移除贯穿全屏的表格垂直线与金额下方的轧账余额噪音。
2. ❌ **严禁说明式文案、过度细化与括号解释**：
   - 所有界面文本严格以最终真实上线产品标准编写，严禁出现任何工程说明、调试占位符、案例堆砌或括号补充；
   - 界面应当像专业文具一样：字句极度凝练、语义自明、留白给数据本身，无说教、无废话、无括号解释；
   - 账本顶栏极致纯粹，右上角不设置主题切换按钮；主题配置统一收拢至资产页「设置」中。
3. ❌ **严禁多层圆角白卡片套娃**：
   - 页面信息组织依靠发丝线、手帐折线虚线与对齐间距，而非浮动的独立白盒子。
4. ❌ **严禁浮夸大圆角**：
   - 纸张裁切是利落的直线，圆角严格限定在 `2px ~ 4px`（最高不超过 `6px`），严禁使用软泡泡式的超大圆角。
5. ❌ **严禁表单内部多层矩形实线边框套娃（去框化原则）**：
   - 表单内部严禁为金额数字、分类磁贴、账户选择器套上密密麻麻的矩形实线框；
   - 贯彻外框拟物、内部去框：金额以无框大字号等宽字体直接展示，分类选中态采用浅色底块配合微倾斜印章高亮，账户与时间以票据单条虚线上下隔离，备注采用手帐本单条虚线下划线。

## 3. 设计标尺与样式类映射

| 维度 | 规约 | 样式类 / 实现 |
|---|---|---|
| **圆角** | 严禁 > 6px | `rounded-xs` (2px), `rounded-sm` (4px), 极少数 `rounded-[6px]` |
| **纸张微噪点** | 全局漫反射棉纸质感 | `.paper-pulp-grain` |
| **撕纸毛边** | 物理微锯齿边缘 | `.paper-deckle` / `.paper-deckle-bottom` |
| **和纸胶带** | 半透明撕边贴带 | `.washi-tape` |
| **卷角悬空阴影** | 非对称纸张翘起 | `.corner-lift-shadow` |
| **数字字体** | 机械打字机与票据等宽 | `font-mono tabular-nums` (Geist Mono) |
| **文学标题** | 书卷文学衬线 | `font-serif-display` (Instrument Serif) |
| **状态标识** | 实体印泥戳印 | `.paper-stamp` / `.real-stamp` |
| **附件标记** | 黄铜回形针 | `.brass-clip`（仅在挂载凭证时展示） |
| **交互动效** | 实体微回弹 | `active:scale-[0.985] transition-transform` |

## 4. 生产级文案与全站对齐规范

- **文案绝对去噪**：
  - 杜绝中英机械混排与全大写修饰词；
  - 避免公文式、会计术语式冗长词汇，例如：“物品清单核算”统一为**“物品总览”**；“往来借贷与报销代收”统一为**“借贷与报销”**；“周期流水明细”统一为**“周期账单”**；“搜索流水备注、分类、账户”统一为**“搜索备注、分类、账户”**；“生命周期流水”统一为**“关联账单”**；
- **全站卡片宽度对齐**：
